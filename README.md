# 직원교육(온라인) 자동 수강 (staff-training-autoplayer)

서울시 평생학습포털의 직원 인권교육을 자동으로 수강신청하고 끝까지 재생해 주는 도구입니다.
설치가 필요 없는 exe 한 개입니다. 켤 때마다 새 버전이 있는지 확인해서, 있으면 안내창을 띄웁니다
(**[예]**를 누르면 브라우저가 새 exe를 내려받으니, 그 파일을 실행하세요. 프로그램이 스스로 파일을 교체하지는 않습니다).

## 사용법
1. [Releases](../../releases/latest)에서 `staff-training-autoplayer.exe`를 내려받아 실행합니다.
   - Windows가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요(서명이 없는 프로그램이라 나오는 경고입니다).
2. 크롬 창이 하나 뜹니다. 거기서 서울시 평생학습포털에 로그인합니다. (이 PC에 **구글 크롬**이 설치되어 있어야 합니다)
3. URL이 들어 있는 공지사항 글을 대충 긁어서 프로그램 창에 붙여넣고 **[시작]**을 누릅니다.
4. 수강신청 → 수강을 쭉 진행하고, 모든 강좌가 끝나면 '완료' 창이 뜹니다. 그 뒤로는 손댈 필요가 없습니다.

- 크롬 창과 프로그램 창은 닫지 마세요. 컴퓨터는 켜 둔 채로 두면 됩니다(절전은 자동으로 막습니다).
- 중간에 껐다면 다음에 켰을 때 **이어서 하기**를 고르면 완료한 강좌는 건너뛰고 이어서 합니다.
- 로그: `%LOCALAPPDATA%\LectureAutoNext\log.txt`

## 개발자용: 릴리스 방법
1. `version.py`의 `__version__`을 올리고 커밋합니다.
2. 같은 번호의 태그를 push 합니다.
   ```
   git tag v1.0.1
   git push origin v1.0.1
   ```
3. GitHub Actions가 exe(`staff-training-autoplayer.exe`)와 체크섬(`.sha256`)을 만들어 릴리스에 올립니다.
4. 사용자의 프로그램은 다음 실행 때 새 버전을 확인해서 안내창을 띄웁니다. 내려받아 실행하는 것은 사용자가 직접 합니다.
   (자기 파일을 교체하고 재실행하는 방식은 안랩 V3 행동 기반 탐지 `DefenseEvasion/MDP.Event.M1423`에 차단되어 쓰지 않습니다.)

테스트: `python test_updater.py`  ·  업데이트 끄기: `autoplayer.py --no-update`
